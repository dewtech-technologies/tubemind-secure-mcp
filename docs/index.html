Why tubemind-secure-mcp?

Turn Claude into a YouTube growth strategist — without ever handing it your raw OAuth tokens.

Plug-and-play with Claude Desktop

Drop one config block, get 18 production tools instantly.

🔐

Secure by default

AES-256-GCM token encryption at rest, SSRF guard, rate limiting, audit log, Zod-validated inputs. OWASP Top 10 mapped end-to-end.

📊

Real data, not scraping

Official YouTube Data API v3 + YouTube Analytics API. Brand Accounts supported.

🧠

Beyond raw API

Built-in heuristics for CTR, retention, keyword difficulty, content gaps, hook angles, N-day calendars.

🪶

Tiny footprint

Only 3 runtime deps (@modelcontextprotocol/sdk, googleapis, zod). Node ≥ 20.

🛡️

Local-only by design

No central server. Tokens stay on your machine. Audit log written locally to a file you own.

Get started in 3 steps

Estimated time: 5 minutes.

1

Install the package

npm install -g tubemind-secure-mcp

Or run on demand: npx tubemind-secure-mcp

2

Authorize your YouTube account

  1. 1. Go to Google Cloud Console → Credentials
  2. 2. Enable YouTube Data API v3 and YouTube Analytics API
  3. 3. Create OAuth 2.0 Client ID → Web application
  4. 4. Authorized redirect URI: http://localhost:4000/oauth/callback
  5. 5. Copy CLIENT_ID and CLIENT_SECRET to .env
  6. 6. Run pnpm auth and sign in with the Google account that owns the channel
YOUTUBE_CLIENT_ID=your-client-id.apps.googleusercontent.com
YOUTUBE_CLIENT_SECRET=your-client-secret
YOUTUBE_REDIRECT_URI=http://localhost:4000/oauth/callback

# generate with: openssl rand -hex 32
TOKEN_ENCRYPTION_KEY=your-64-char-hex-key

RATE_LIMIT_PER_MINUTE=60
REQUEST_TIMEOUT_MS=10000
AUDIT_LOG_PATH=./logs/audit.log
NODE_ENV=production
3

Add to Claude Desktop

Edit claude_desktop_config.json (%APPDATA%\Claude\ on Windows, ~/Library/Application Support/Claude/ on macOS): 

{
  "mcpServers": {
    "tubemind": {
      "command": "npx",
      "args": ["-y", "tubemind-secure-mcp"],
      "env": {
        "YOUTUBE_CLIENT_ID": "...",
        "YOUTUBE_CLIENT_SECRET": "...",
        "YOUTUBE_REDIRECT_URI": "http://localhost:4000/oauth/callback",
        "TOKEN_ENCRYPTION_KEY": "...",
        "NODE_ENV": "production"
      }
    }
  }
}

Restart Claude Desktop. The 18 tools appear automatically.

Secure by design

Mapped to OWASP Top 10. See SECURITY.md for the full posture.

Risk Mitigation
A01 — Broken Access ControlOAuth2 scopes least-privilege, audit log per call
A02 — Cryptographic FailuresAES-256-GCM at rest for tokens, secrets via env only
A03 — InjectionZod schemas on every tool input
A04 — Insecure DesignRate limit, request timeout, SSRF guard (host whitelist)
A05 — Misconfiguration.env.example template, no leaky defaults
A07 — AuthN FailuresOAuth2 PKCE-style flow, encrypted token storage
A08 — IntegrityPinned deps, pnpm audit in CI, dependabot
A09 — Logging FailuresAudit log of every tool call (timestamp, tool, success)
A10 — SSRFOutbound calls restricted to googleapis.com family
