Privacy Policy

Effective date: 7 May 2026 · Last updated: 7 May 2026

1. Who we are

tubemind-secure-mcp ("the Software") is an open-source Model Context Protocol (MCP) server published by Dewtech Technologies ("we", "us") and made available under the MIT License at github.com/dewtech-technologies/tubemind-secure-mcp and on npm as tubemind-secure-mcp.

Contact: wleandro.oliveira@gmail.com

2. Scope of this policy

This policy describes how the Software handles user data when installed and run locally on a user's own machine. We do not operate any backend, server, telemetry endpoint or analytics service for the Software. The Software is a standalone tool that runs on your computer and communicates only with Google's official YouTube APIs using credentials you provide.

3. Data we do NOT collect

We want to be unambiguous about this:

  • We do not operate any server that the Software talks to.
  • We do not receive any telemetry, usage metrics or analytics from the Software.
  • We never see your YouTube account, channel, videos, analytics, OAuth tokens or API keys.
  • We do not sell, share, rent or transfer any user data — because we never receive any.

4. Data the Software handles locally on your machine

The Software handles the following data, all of it stored exclusively on your local file system:

4.1 Google OAuth credentials

  • What: The OAuth Client ID, Client Secret and access/refresh tokens issued by Google when you authorize the Software to use your YouTube account.
  • Where: Tokens are persisted to ./tokens/youtube.token.json within your project directory. Client ID/Secret are read from environment variables (.env file).
  • Protection: Tokens at rest are encrypted with AES-256-GCM using a 256-bit key (TOKEN_ENCRYPTION_KEY) that you generate locally. The key is never transmitted.
  • Retention: Until you delete the tokens/ directory, revoke access at myaccount.google.com/permissions, or uninstall the Software.

4.2 Audit log

  • What: A line-per-call log written to a path you configure (default ./logs/audit.log) containing: timestamp, tool name, action, success/failure flag.
  • Why: So you can review which YouTube operations were performed and detect misuse on your own machine.
  • Where: Local file system only. Never transmitted.
  • Retention: You manage the file (rotate, delete or archive at any time).

4.3 YouTube data fetched on demand

  • What: Public and private YouTube data (channel analytics, video metadata, search results) fetched from Google's official APIs when an MCP tool is invoked.
  • Where: Held in process memory only, returned to the MCP client (e.g. Claude Desktop), and discarded when the process exits. Not persisted by the Software.

5. Google API Services User Data Policy compliance

tubemind-secure-mcp's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Specifically:

  • We use YouTube data only to provide and improve the user-facing features of the Software (the 18 MCP tools listed at tubemind.dewtech.tech).
  • We do not use the data for serving advertisements.
  • We do not transfer or sell the data to third parties.
  • We do not allow humans to read the data unless we have your explicit consent for specific items, the data is needed for security purposes (such as investigating abuse), to comply with applicable law, or for the Software's internal operations and the data is aggregated or anonymized.

6. OAuth scopes used and why

The Software requests the minimum scopes required to deliver its features:

  • youtube.readonly — to read channel and video metadata for analysis tools (get_video_tags, list_channel_videos, get_competitor_videos, search/heuristic tools).
  • yt-analytics.readonly — to read your channel's analytics for the analytics and benchmark tools (get_channel_analytics, score_best_publish_window, benchmark_channel).
  • youtube — to update titles, descriptions and tags of your own videos via update_video_metadata. The Software verifies channel ownership before any write.
  • youtube.upload — reserved for future upload features. Not actively used by any current tool.

You can revoke any of these scopes at any time at myaccount.google.com/permissions.

7. Security measures

  • AES-256-GCM encryption for OAuth tokens at rest.
  • SSRF guard: outbound requests are restricted to the googleapis.com family of hosts.
  • Rate limiting: per-tool rate limits to protect Google API quota and detect abuse.
  • Input validation: every MCP tool input is validated with Zod schemas before reaching Google APIs.
  • Audit logging: every tool call is recorded in a local audit log.
  • Dependency hygiene: pinned versions, automated pnpm audit in CI, Dependabot enabled.

Full security posture mapped to OWASP Top 10 is published in SECURITY.md.

8. Children's privacy

The Software is a developer tool not directed at children. We do not knowingly collect any personal information from anyone, including children under 13.
