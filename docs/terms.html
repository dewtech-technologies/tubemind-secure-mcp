3. What the Software does

The Software is a Model Context Protocol (MCP) server. When connected to an MCP-compatible client such as Anthropic's Claude Desktop, it exposes 18 tools that interact with the official YouTube Data API v3 and YouTube Analytics API on behalf of the user, using OAuth credentials supplied by the user.

The Software runs entirely on the user's machine. Dewtech Technologies ("we") does not operate any backend, server or hosted service for the Software.
